# Metro Interstate Traffic Volume Forecasting using Hybrid SARIMA

## Overview

This project forecasts hourly metro interstate traffic volume using classical statistical and machine learning techniques.

A Hybrid SARIMA-Hourly Ratio model was developed to improve forecasting accuracy over conventional approaches.

---

## Objectives

- Traffic forecasting
- Trend analysis
- Seasonal analysis
- Time-series modeling

---

## Models Used

- Linear Regression
- ARIMA
- SARIMA
- Hybrid SARIMA-Hourly Ratio

---

## Workflow

Data Collection
↓
Preprocessing
↓
EDA
↓
ADF Stationarity Test
↓
Model Training
↓
Forecast Generation
